# Shared Money local-first release
## Authorized scope
Implement the supplied shared-expense product proposal without connected Supabase, authentication, bank/payment integrations or subscriptions; deploy on Render. The document's later backend-dependent features are deferred. Existing SALON and studio main branches must not be changed.
## Architecture
Next.js static export, React and TypeScript. IndexedDB repository serializes atomic validated workspace mutations. No persisted balance field. Monetary math uses integer cents and BigInt intermediate products. Each expense stores immutable split amounts, edits reallocate. Deterministic largest-remainder allocation. Greedy creditor/debtor matching reduces transfer count; not advertised as globally optimal. Payments reduce liabilities and leave expenses unchanged. Deletion is soft, restoration logs history. Schema validation on persisted data, backups and snapshot links.
## Screens and flows
Empty groups home → name and group type → group name, currency and optional member names → group. Explicit sample group for exploration. Group has Expenses, Balance, Group tabs. Quick add amount/title defaults current member/today/equal. Optional settings for payer/date/split/notes/receipt. Advanced modes exclude members, shares, exact cents, percentage in basis points. Validation rejects bad totals/empty participants and invalid dates.
Balance explains each member's paid/consumed/transferred amounts, lists suggested transfers and registers a manual payment with explicit statement that money is not sent. Settlement undo. Member addition/rename, identity switch, group rename/archive, activity history. Snapshot share excludes receipts and invites an independent copy, never claims collaboration. Backup JSON and CSV export. Search and categorized expenses.
## Persistence and errors
Atomic IndexedDB commits only update UI after completion. Save errors retain forms, show retry, no indefinite spinner. Initialization can retry; corrupt data never overwritten. Backup import validates and adds independent group copies. Schema version 1. Concurrent tab writes serialize in IndexedDB transactions. Receipt limit 2MB, images only; links capped and validated. PWA caches static shell/resources and allows local operations offline after first load.
## Tests and acceptance
Unit tests for €10/3 = 334+333+333, decimal parsing, percentage/exact validation, member exclusions, refund not supported, balances sum zero, registered transfers settle without altering expenses, soft-delete/restore, malicious/corrupt imports and atomic/concurrent persistence. Browser tests for creation, add/edit/delete/undo, all split modes, members, balance/payment undo, exports, snapshot import, reload, empty/search states, offline, failed save and recovery, long text and 320/390/768/1440 viewports. Typecheck/lint/build before release. Render live deploy status and live browser smoke check on exact source commit.
