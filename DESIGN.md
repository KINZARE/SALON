# Shared Money visual system
Light editorial utility for quick repeated tasks, designed for use on trips in daylight. DM Sans, ink #202922, warm paper #fafaf7, white surfaces, forest #365641 as the action color, clay accent #b96848 sparingly. Clear tabular monetary values, roomy line-based lists, compact metadata. No gradients, decorative dashboards or excessive cards.

Desktop: 252px quiet left navigation, top header, central group list/content with contextual balance side panel. Mobile: compact header, stacked summaries, horizontally scrollable three-tab group navigation and reachable primary button. 44px targets, visible focus, native dialog focus management, inline errors and save/undo status. Functional motion only, 160ms ease-out, reduced motion support.
